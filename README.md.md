## Objetivo

Desenvolver um programa em C utilizando um vetor de 20 posições, estruturas de repetição, condicionais e operações matemáticas.

## Funcionamento

O programa:

- Armazena 20 números inteiros em um vetor;
- Calcula a soma dos múltiplos de 3;
- Calcula a média dos números pares;
- Conta os números positivos e negativos;
- Identifica o maior e o menor valor;
- Exibe todos os elementos armazenados.

A média dos números pares é calculada somente quando existe pelo menos um número par, evitando divisão por zero. O valor zero não é contabilizado como positivo ou negativo.

## Como executar

O programa pode ser compilado e executado utilizando o **OnlineGDB**, selecionando a linguagem C, inserindo o código no editor e clicando em **Run**.
